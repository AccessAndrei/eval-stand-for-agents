# ADR

[`0000-template.md`](0000-template.md) — форма для будущего ADR, не принятое решение.

Обязательный минимум из A-10 и покрывающие его решения:

| Тема | ADR и статус |
|---|---|
| Харнес | [0001 — Codex и Python-адаптер](0001-codex-python.md), accepted |
| Сандбокс и способ запуска | [0002 — полномочия менеджера и доверенный сборщик](0002-sandbox-authority.md), accepted |
| Транспорт клиент ↔ сервер | Не выбран; HTTP раннера не заменяет решение для десктоп-клиента |
| Транспорт харнес ↔ сандбокс | [0003 — stdio через CONNECT](0003-stdio-transport.md), accepted |
| Механизм монтирования | Не выбран; требуется сравнение минимум с двумя альтернативами |
| Модель сессий | [0004 — жизненный цикл попытки](0004-run-lifecycle.md), accepted для одного активного run; пользовательские и параллельные сессии отложены |
| Сетевая политика | [0002](0002-sandbox-authority.md) задаёт запрет сети сандбокса; политика клиентского монтирования ещё не выбрана |
| Выбор пары «харнес + LLM» по БАФ | Не принят: полного сравнительного эксперимента пока нет |

Принятие архитектурного решения не означает прохождение всех интеграционных проверок; их статус хранится в [отчёте](../report.md).

Транспорт десктоп-клиента, клиентское монтирование и его альтернативы, долгоживущие пользовательские сессии и выбор лучшей пары по полному БАФ относятся к следующим итерациям. Сеть текущего сандбокса запрещена; только посредник должен иметь внешний маршрут к фиксированному провайдеру. Изоляция текущего offline-контура и отказ от локального обхода проверены. Сетевая политика клиентского монтирования и полный hardening задания A относятся к следующим итерациям.

Устаревшие ADR не удаляются, а помечаются `superseded`.

[0005 — API-ключ и адаптеры провайдера](0005-api-provider.md), accepted: текущий способ подключения внешней модели с 2026-11-14. Старые Luna/OAuth-результаты остаются историческими и не подтверждают новую live-интеграцию.
