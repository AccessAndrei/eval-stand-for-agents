# ADR-0002: полномочия менеджера и доверенный сборщик

- Статус: accepted
- Дата: 2026-11-06

## Контекст

Создание Docker-контейнеров требует широких полномочий. Агентные команды и изменяемые файлы не должны получать Docker socket или авторизацию модели. После задания необходимо остановить писателей и получить стабильную копию до исчезновения tmpfs.

## Решение

Только sandbox-manager получает Docker socket. Внешний интерфейс ограничен run/project/handle, fingerprint и фиксированными операциями. Рабочая среда: непривилегированные пользователи, read-only root, cap-drop ALL, no-new-privileges, network none и ограничения ресурсов. Исходные файлы B5.1 монтируются отдельно read-only.

По согласованному решению пользователя сборщик работает в отдельном служебном контейнере, разделяет PID namespace только с проверенной собственной средой и получает KILL, SYS_PTRACE и DAC_READ_SEARCH. Это текущий минимальный кандидат набора capabilities: окончательная минимальность и защита от вмешательства должны подтверждаться интеграционным тестом. Агент эти capabilities не получает. Сборщик останавливает процессы UID агента, затем читает `/work` через mount namespace живого supervisor; tmpfs сохраняется до конца чтения. Объём и типы файлов ограничены, ссылки и traversal отклоняются.

## Альтернативы

| Вариант | Преимущество | Причина отказа |
|---|---|---|
| Socket в харнессе | Меньше посредников | Необоснованно расширяет полномочия агента |
| Сборщик с UID агента | Не нужны дополнительные capabilities | Агент может вмешиваться в его процесс |
| Остановить контейнер до копирования | Простая очистка | Уничтожается tmpfs с результатами |
| Заморозить и скопировать | Стабильное дерево | Не выполняет выбранный порядок уничтожения процессов до сбора |

## Последствия

Менеджер остаётся доверенным компонентом с полномочиями, близкими к root Docker-хоста. Сборщик входит в учёт CPU/RAM, labels, восстановление и очистку; он не пятый постоянно работающий сервис. Неудача подтверждения остановки или сбора даёт неполный результат. [Код](../../services/sandbox_manager/manager.py), [ограничения проверки](../report.md).
