# Десктоп-клиент

Клиент отложен в текущей итерации; реализации и исполняемой CLI здесь пока нет.
Сейчас задания запускает Python-раннер `baf/runner/`.

Будущий клиент должен выбирать и монтировать локальную папку, показывать чат
и события, отменять запуск и переподключаться. Требования и границы текущей
итерации приведены в [дизайн-документе](../docs/ml_system_design_doc.md).
