# Формирование slug

Функция `slugify(text)` принимает строку. Она выделяет группы из латинских
букв ASCII и цифр `0`-`9`, переводит буквы в нижний регистр и соединяет
группы одним дефисом. Любой другой символ служит разделителем.
Если групп нет, функция возвращает пустую строку.

| Вход | Результат |
|---|---|
| ` Hello, World! ` | `hello-world` |
| `item_42 / A` | `item-42-a` |
| `---` | пустая строка |
