# Десктоп-клиент

Клиент отложен в текущей итерации; реализации и исполняемой CLI здесь пока нет.
Сейчас задания запускает Python-раннер `baf/runner/`.

Будущий клиент должен подключаться по адресу сервера и токену, выбирать
локальную папку и монтировать её как `/work` в режиме ro/rw, показывать чат
и поток событий, отменять запуск и переподключаться после обрыва.
Изменения файлов должны быть видны в обе стороны; клиент и сервер должны
работать на разных машинах. Стек и команды сборки пока не выбраны.

## Headless / CLI-режим

Для UI- и инфраструктурных автотестов нужен режим без графического интерфейса:
подключение, монтирование, отправка сообщения, изменение файла по сценарию
и отмена. Он должен использовать общий протокол с графическим клиентом.
Исполняемых команд пока нет.

Целевые требования описаны в [дизайн-документе](../docs/ml_system_design_doc.md),
текущая готовность — в [отчёте](../docs/report.md).
