# ADR

Принятые решения текущей итерации:

Принятие архитектурного решения не означает прохождение всех интеграционных проверок; их статус хранится в [отчёте](../report.md).

Транспорт десктоп-клиента, клиентское монтирование и его альтернативы, долгоживущие пользовательские сессии и выбор лучшей пары по полному БАФ относятся к следующим итерациям. Сеть текущего сандбокса запрещена; только посредник должен иметь внешний маршрут к фиксированному провайдеру. Полная проверка этой политики остаётся отдельным интеграционным этапом.

Устаревшие ADR не удаляются, а помечаются `superseded`.
