# ADR-0001: штатный Codex и Python-адаптер

- Статус: accepted
- Дата: 2026-11-06

## Контекст

Нужен открытый харнесс с инструментами командной строки и правки файлов. Собственный код проекта должен оставаться на Python; ядро агентного цикла не требуется переписывать.

## Решение

Закрепить Codex 0.159.3 на commit `01fc69f4026735edfdf6789820549727a4867b11`. Python-адаптер управляет `app-server` через штатный JSON-RPC, создаёт ephemeral thread с отдельным CODEX_HOME и выбирает единственную удалённую среду. Перед запуском проверяется фактическая версия бинарника. Сборка из исходников и происхождение фиксируются отдельно от диагностического upstream-бинарника.

## Альтернативы

| Вариант | Преимущество | Причина отказа |
|---|---|---|
| Собственный агентный цикл | Полный контроль протокола | Повторяет функции выбранного открытого компонента |
| Форк Codex | Можно менять внутренние инструменты | Усложняет обновление и воспроизведение |
| Node.js-адаптер | Есть примеры интеграции | Не соответствует выбранному Python-стеку собственного кода |

## Последствия

Экспериментальный API требует закрепления версии и реального теста выбора среды. Чистый каталог исключает наследование личных hooks/skills. Ограничение shell environment должно проверяться в фактически исполненной команде. Реализация: [harness](../../services/harness/adapter.py). Статус source-build и native-интеграции: [отчёт](../report.md).
