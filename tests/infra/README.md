# Инфраструктурные тесты

Набор использует Codex, Docker-сандбоксы и mock LLM без внешней сети.
После [подготовки сервера](../../README.md#запуск-сервера) остановите стек,
соберите образы и запустите тесты из корня репозитория.

```bash
docker compose -f docker-compose.yml -f docker/compose.mock.yml \
  -f docker/compose.single-cpu.yml --profile tools build --builder "$BUILDX_BUILDER"
docker buildx stop "$BUILDX_BUILDER"
make preflight-shared
make test-infra
```

На x86_64 используйте `linux/amd64` и сборку Codex под ту же архитектуру.
Набор сам запускает и останавливает mock-стек. Сводка и журналы
сохраняются в `results/offline-suite-*`.

| Группа | Проверки |
|---|---|
| Контракты | Схемы протоколов и граничные случаи |
| Инварианты | Ровно один result, идемпотентность, отмена дерева процессов, таймауты операций, отсутствие секретов в сандбоксе |
| Лимиты и очистка | CPU, RAM, PIDs, диск, время; отсутствие процессов и временных ресурсов после сессии |
| Изоляция | Выход за workdir, внешние симлинки, canary-секрет, fork bomb, заполнение диска, запись в ro; текущие проверки сборщика не заменяют весь набор |
| Сеть | Разрешённое доступно, запрещённое заблокировано, обход невозможен |
| Сбои | Обрывы монтирования и клиента, падение харнеса посреди команды, политика ретраев |
| Сессии | Один активный запуск на сессию и изоляция сессий |
| Синхронизация | Правки видны в обе стороны, конфликт одновременной правки обрабатывается по ADR; пока не реализовано |

В таблице указано требуемое покрытие. Результаты выполненных сценариев
указаны в [сводках](../../results/README.md#опубликованные-сводки).

[Сценарий отмены и продолжения в том же /work](../../docs/adr/0006-mounted-client-runtime.md#воспроизведение) запускается отдельно на Compose с mock-провайдером.
